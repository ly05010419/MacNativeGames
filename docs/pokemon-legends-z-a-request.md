# Game support request: Pokémon Legends: Z-A

I would like to play **Pokémon Legends: Z-A (宝可梦传说 Z-A)** on an
Apple silicon Mac through MacNativeGames. Please consider adding support for
the Nintendo Switch version using the project's native ARM64 and Metal approach.

The desired result is a Mac app built from the player's own game files, with
working controls, world exploration, battles, audio, and saving/loading.
Reaching the title screen alone would be an initial milestone; playable gameplay
would still need validation.

This document records a feature request. It does not add a port, claim game
compatibility, specify a supported game version, or promise a delivery date.

希望 MacNativeGames 考虑支持 Nintendo Switch 版《宝可梦传说 Z-A》，
让玩家能在 Apple 芯片 Mac 上，通过项目现有的原生 ARM64 与 Metal 路线游玩。

期望能用玩家自己的游戏文件构建 Mac App，并正常使用操作、地图探索、对战、
声音和存档读取功能。进入标题画面可以作为初步里程碑，实际可玩性仍需验证。

本文仅记录功能请求，不包含移植实现，也不代表游戏已经兼容或承诺完成时间。
