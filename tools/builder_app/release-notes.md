Download **MNG-Launcher-…-macOS-arm64.zip** from Assets, unzip it and move **MNG Launcher.app** into Applications.
Requires an Apple silicon Mac running macOS 26 or later. No Launcher compilation, Python installation or source checkout is needed.

This preview is ad-hoc signed, **not Apple notarized**. macOS may block its first launch. After verifying the download's
source, use System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper globally.

The app includes its matching build scripts and Python. At first use it prepares the scripts under
`~/Library/Application Support/MacNativeGames/Builder/sources`; subsequent launches reuse them.
Building a game still requires Apple's command line developer tools, sufficient disk space and your own game files and keys.
No game files or keys are included. Download a newer Launcher release to update the Launcher and its build scripts together.
